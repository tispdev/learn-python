# learn-python
A beginner-friendly collection of Python scripts to learn Python basics.  

Description:
This repository includes simple Python programs, including core concepts — such as variables, control flow, loops, functions, lists, dictionaries, user input, and basic algorithms.


Programs:

- area_calculator.py – Asks the user for measurements (length, width) and calculates the area.

- codebuilders_dictionaries.py – Teaches how to create and use dictionaries.
  
- codebuilders_functions.py – Shows how to define and call functions, return values, and organize reusable code.
  
- codebuilders_list.py – Demonstrates how to create lists, loop through them, modify them, and perform list operations.
  
- codebuilders_loops.py – Shows how to use for and while loops to repeat tasks.
  
- codebuilders_miniproject_conditional_and_loop.py – A mini-project combining conditionals and loops together in one program.
  
- color_and_age.py – Asks the user for their favorite color and age, then prints responses based on their input.
  
- conditional_age_checker.py – Uses if/elif/else to check someone’s age and print a message (like child, teen, adult).
  
- conditionals_test.py – A simple test program for practicing conditional statements using different conditions.
  
- countdown.py – Counts down from a given number to zero using a loop (and may print a final message when done).
  
- hello.py – Prints “Hello World!”.
  
- simple_voting_checker.py – Asks for the user’s age and checks if they are old enough to vote using conditionals.
  
- user_data_collector.py – Collects multiple pieces of information from the user, stores them, and prints the results.
  
- user_input.py – Demonstrates how to take user input, convert it to numbers, and respond based on the input.

- repeat_greeting.py - Asks user for a name, then asks user whether or not they would like to say hi to the person.

- shopping_list.py - This program prints out a shopping list, and modifies the second item.

- favourite_things.py - This program prints 5 items, and asks the user for their favorite item.

- math_helper.py - This programs takes a number and doubles it and also check's if it's even or not.

- greeting_machine.py - This program takes user name and age and relays it.

- number_game.py - This program is a game where the user guesses the secret number (1-10) and is given 3 tries with hints.
